# 小克：问题与 Bug 反馈

反馈邮箱：[support@lqstudio.uk](mailto:support@lqstudio.uk)。也可在本仓库发起 Issue；

## 反馈模板

```text
主题：[小克][版本号] 问题简述

应用版本 / 提交号：
正式版或 OCR 测试版：
手机品牌和型号：
Android / 厂商系统版本：
触发入口：长按电源键 / 快捷设置磁贴 / 无障碍按钮 / 应用内
功能：快速翻译 / 深度翻译 / 文本对话 / 系统语音 / 实时语音
模型服务商和模型名（不要填写 API Key）：
流式输出：开 / 关

复现步骤：
1.
2.
3.

预期结果：
实际结果：
是否每次都发生：
能否在不含私人内容的测试页面复现：
可选附件：脱敏截图、相关错误片段或测试结果
```

如果反馈“长按电源键又回到 YOYO”，可附配置指南中助手角色、语音交互绑定及 YOYO 启用状态的脱敏结果。不要附完整系统账户列表或全量手机日志。

如果反馈“语音没有识别”，请注明设置 → 语音 → 识别服务的名称、是否授予麦克风权限及是否联网。语音识别和翻译模型是不同环节。

如果反馈“漏译、残留字形或覆盖图标”，请尽量提供同一页面的原图与译图，保留问题区域，遮去无关个人信息。

请勿发送 API Key、私钥、签名密钥库、无线调试配对码、设备序列号、完整聊天记录或其他不必要的个人数据。邮件由用户主动发送；软件不会自动收集这些反馈材料。
